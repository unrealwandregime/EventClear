# Privileged roles

- Relationship registry: default administrator, reviewer, suspender.
- Risk policy: default administrator, risk administrator, vault.
- Vault: default administrator and pauser.
- Funding pool: default administrator, vault and allowlisted LP.
- Claims: default administrator and vault mint/burn role.
- Treasury: default administrator and fee recorder.
- Offchain: AWS deploy role, staging API task role, KMS key policy, database
  migration role, DNS/TLS operator and GitHub staging approver.

Review role grants, revocations, renunciations and monitoring for every change.
